## 1. Задача пользователя

Покупатель ищет товар в категории из 200+ позиций. Сейчас список без фильтров: чтобы найти нужный размер и цену, он листает восемь экранов и уходит.

## 2. Зачем бизнесу

Отвал на каталоге — 41% сессий; фильтры должны сократить путь до товара.

## 3. Scope

**Входит:**
- Экран каталога со списком и панелью фильтров
- Все состояния списка
- Поведение фильтров: применение, сброс, счётчик

**Не входит:**
- Поиск по тексту — отдельная задача ACM-149
- Сортировка — есть, не меняется
- Карточка товара — не трогаем

## 4. Требования

| # | Требование |
|---|---|
| R1 | Когда открыт каталог без фильтров, показываются все товары категории |
| R2 | Когда применён фильтр, список обновляется без ухода с экрана |
| R3 | Когда под фильтр не попал ни один товар, показывается состояние с предложением сбросить фильтры |
| R4 | Когда фильтры применены, их количество видно на кнопке фильтров |
| R5 | Когда пользователь вернулся на каталог с карточки товара, фильтры сохранены |
| R6 | Когда список загружается, показывается скелетон, повторяющий сетку карточек |

## 5. Критерии приёмки

| # | Given | When | Then |
|---|---|---|---|
| AC1 | Каталог с 200 товарами | пользователь выбрал размер M | список показывает только размер M, счётчик на кнопке = 1 |
| AC2 | Применены 3 фильтра | пользователь нажал «Сбросить» | все фильтры сняты, список полный, счётчик исчез |
| AC3 | Фильтры дают 0 результатов | список отрисован | видно объяснение и кнопка «Сбросить фильтры» |
| AC4 | Каталог открыт | сеть недоступна | показано offline-состояние с кэшированным списком |
| AC5 | Применён фильтр | пользователь открыл товар и вернулся назад | фильтр сохранён, позиция скролла восстановлена |

## 6. Матрица состояний

| Экран | empty | empty-filtered | loading | partial | error | offline | success | data |
|---|---|---|---|---|---|---|---|---|
| Каталог | ✅ | ✅ | ✅ | н/п | ✅ | ✅ | — | ✅ |
| Панель фильтров | — | — | ✅ | — | — | — | — | ✅ |

**Обоснования:**
- `partial` — н/п: список грузится одной страницей, частичной отдачи нет
- `success` — не требуется: применение фильтра не является завершённым действием, подтверждение не нужно

## 7. Guardrails

- Не менять публичные компоненты Acme DS — только композиция из существующих
- Панель фильтров собирается из `Sheet/Bottom` и `Chip/Filter`, новых компонентов не заводим
- Уложиться в spacing-шкалу 4, 8, 12, 16, 24, 32, 48, 64
- Не трогать сортировку и карточку товара
