## Что делаем

Каталог категории с фильтрацией по размеру, цвету и цене. Фильтры применяются мгновенно, список обновляется без перехода.

## Адаптив

| Брейкпоинт | Что меняется |
|---|---|
| ≥1280 | фильтры боковой панелью слева 280pt, сетка 4 колонки, кнопки фильтров нет |
| 768–1279 | панель 240pt, сетка 3 колонки. **4 колонки не использовать** — название товара обрезается до двух слов |
| <768 | панель скрыта, появляется кнопка «Фильтры» со счётчиком, панель открывается в bottom sheet 80% высоты, сетка 2 колонки |

Переход 768 → 767: боковая панель схлопывается, её содержимое переезжает в sheet без изменения порядка групп.

## Поведение

- Фильтр применяется **сразу** при выборе чипса, без кнопки подтверждения. Кнопки «Применить» в sheet нет.
- Во время запроса список показывает скелетон; уже выбранные чипсы остаются активными и кликабельными.
- Повторное нажатие на чипс во время запроса отменяет предыдущий запрос и запускает новый. Очередь не копится.
- Счётчик на кнопке «Фильтры» показывает число применённых фильтров, не число выбранных значений: размер M + размер L = 1.
- «Сбросить фильтры» снимает все фильтры и скроллит список наверх.
- Фильтры сохраняются **до конца календарного дня** (по Q2), между сессиями в том числе. После полуночи сбрасываются.
- При возврате с карточки товара восстанавливаются и фильтры, и позиция скролла.
- При потере сети показывается offline-состояние с последним закэшированным списком; фильтры при этом заблокированы, чипсы в `disabled`.
- Ошибка запроса → error-состояние с кнопкой «Повторить». Повтор возвращает в loading.

|---|---|---|---|---|---|---|
| Bottom sheet | нажатие «Фильтры» | translateY | 100% → 0 | 300мс | ease-out | 0 |

| Bottom sheet | закрытие | translateY | 0 → 100% | 250мс | ease-in | 0 |
| Чипс | выбор | background | `surface/base` → `action/primary` | 120мс | ease-out | 0 |

При `prefers-reduced-motion` sheet появляется через opacity 150мс без сдвига.

## Доступность

- Кнопка «Фильтры»: `spec:label` = «Фильтры, применено: N»
- Sheet: `spec:role` = `dialog`; при открытии фокус на заголовок, при закрытии возвращается на кнопку «Фильтры»
- `spec:focus-order` в sheet: заголовок → группы чипсов сверху вниз → «Сбросить» → «Закрыть»
- Чипсы: состояние `focused` — обводка 2pt `border/focus`, контраст 3.2:1
- Счётчик товаров: `spec:live` — объявляется при изменении списка («Найдено 24 товара»)
- Изображения товаров: `spec:alt` = название товара
- Плейсхолдер изображения: `spec:decorative`
- Все чипсы ≥44pt по высоте, между соседними 8pt
